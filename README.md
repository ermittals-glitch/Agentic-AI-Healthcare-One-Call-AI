# OneCall AI

"One member. One representative. One resolution — reducing transfers, repeat calls, handle time, and servicing cost."

## Problem

Healthcare payer member issues can span eligibility, benefits, claims, prior authorization, and provider information. Representatives may need to navigate multiple systems or transfer members between departments to resolve a single issue.

## Solution

OneCall AI will use specialized AI agents coordinated by an orchestrator to investigate payer domains, maintain shared case context, and recommend the next best action to one representative.

## Project Scope

This repository contains a Week 3 Agentic AI prototype.

## Synthetic Data

No real PHI or member information is used.

## Test Scenarios

1. Claim denied despite approved authorization
2. Authorization actually missing
3. Coverage showing inactive
4. Payer system failure and recovery
